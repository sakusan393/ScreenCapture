# 393 ScreenCapture 1.1.0

- Status: published

## Changes

- エクスプローラーでコピーした JPG / JPEG / PNG ファイルをキャプチャウィンドウへ貼り付けられるようにした。
- 複数画像の貼り付け、透過 PNG の透明度維持、画像ビューワー由来の DIB / DIBV5 貼り付けに対応した。
- キャプチャ領域より大きい貼り付け画像を、縦横比を維持したまま自動縮小するようにした。
- キャプチャ背景色の Alpha 0 を 1 へ補正し、透明な余白からもウィンドウをドラッグできるようにした。
- カラーピッカーのポップアップ操作とヒットテストを改善した。
