# Microsoft Store screenshots

ルート直下の `01` から `04` の PNG は日本語、`en-US/` の同名 PNG は英語の Microsoft Store デスクトップ向けスクリーンショットです。すべて 1600 x 900 です。

- `01-capture-range.png`: 範囲選択画面
- `02-edit-and-annotate.png`: テキスト、ペイント、矢印、Layers
- `03-color-and-alpha.png`: 色とアルファ値を扱うカラーピッカー
- `04-hotkey.png`: グローバルホットキー設定

画面部分は実行中の ScreenCapture から取得した画像です。説明用の見出しは画面の外側にだけ配置し、アプリ UI 自体には描き足していません。

日本語版の編集元は `source/01-capture-range.svg` から `source/04-hotkey.svg`、英語版は同じファイル名に `.en-US` を付けた SVG です。`preview-contact-sheet.png` と `en-US/preview-contact-sheet.png` は、それぞれの言語の4枚をまとめた確認用画像で、Storeへは登録しません。

Store へは各言語とも上記の順に登録してください。最初の3枚を優先し、4枚目は補足として使用します。
